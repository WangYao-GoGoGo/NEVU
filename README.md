# Experimental Code for Event-centric Human Value Understanding in News-domain Texts

This repository contains the experimental code used in our study:

**event-centric human value understanding in news-domain texts: an actor-conditioned, multi-granularity benchmark**

## Notice

Please note that this repository is currently provided as a **preliminary experimental version**.

The code has not yet been fully cleaned, refactored, or documented as a formal reproducible release. Some scripts may still contain project-specific structures or require additional configuration before they can be directly executed in a different environment.

At this stage, the repository is mainly intended to help interested researchers understand the experimental pipeline, task construction process, prompt-based evaluation, fine-tuning setup, and analysis scripts used in our work.

We will continue to organize, update, and improve the repository gradually. A more complete and better-documented version will be prepared in the future.

## Current Status

- Experimental code is provided for reference.
- Some scripts may require manual adaptation.
- Documentation is still incomplete.
- The repository will be updated progressively.
- The released dataset can be used together with this code for research reference.
